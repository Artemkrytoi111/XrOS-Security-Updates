XrOS — обновления безопасности

Официальный репозиторий обновлений безопасности XrOS 1.0 Diamond. Установленная система скачивает отсюда обновления собственных пакетов XrOS через pacman.

Настройка в системе

[xros]
SigLevel = Optional TrustAll
Server = https://artemkrytoi111.github.io/XrOS-Security-Updates/xros/os/$arch

Обновление системы: sudo pacman -Syu

Что здесь лежит

Пакеты xros-installer, xros-welcome, xros-branding, xros-cli и база репозитория xros.db.tar.gz в каталоге xros/os/x86_64/. Подробности — в README репозитория.

Основной проект XrOS: github.com/Artemkrytoi111/XrOS
