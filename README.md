# XrOS — репозиторий обновлений безопасности

Это официальный репозиторий обновлений безопасности **XrOS 1.0 Diamond**.

Установленная система XrOS скачивает отсюда обновления собственных
пакетов XrOS через pacman (репозиторий `xros`):

```
[xros]
SigLevel = Optional TrustAll
Server = https://artemkrytoi111.github.io/XrOS-Security-Updates/xros/os/$arch
```

## Что здесь лежит

```
xros/os/x86_64/
  *.pkg.tar.zst        — пакеты XrOS (xros-installer, xros-welcome,
                         xros-branding, xros-cli)
  xros.db.tar.gz       — база данных репозитория (pacman)
  xros.db              — то же, без суффикса (так запрашивает pacman)
  xros.files.tar.gz    — список файлов пакетов
  xros.files           — то же, без суффикса
```

Текущие версии: xros-installer 1.0-3, xros-welcome 1.0-2,
xros-branding 1.0-2, xros-cli 1.0-1.

## Как обновить систему

На установленной XrOS:

```
sudo pacman -Syu
```

## Что обновляется отсюда, а что нет

- **Отсюда** — только собственные пакеты XrOS (установщик, приветствие,
  брендинг, команда `xros`). Когда в них исправляется уязвимость или
  ошибка, новая версия публикуется здесь, и система подхватывает её
  через обычное `pacman -Syu`.
- **Не отсюда** — обновления самой Arch Linux (ядро, системные
  библиотеки и программы): они приходят из официальных репозиториев
  Arch (core/extra/multilib), которые уже настроены в системе.

## Как публикуется обновление (для разработчика)

1. Собрать новый пакет в проекте XrOS (`~/workspace/xros/packages/...`).
2. Обновить базу репозитория в проекте: `repo-add`
   `repo/xros/os/x86_64/xros.db.tar.gz <новый пакет>`.
3. Скопировать новые файлы в этот репозиторий
   (`xros/os/x86_64/`), обновить копии `xros.db` / `xros.files`.
4. Сделать коммит и push в `main` — GitHub Pages публикует
   изменения автоматически (обычно за 1–2 минуты).

Репозиторий публичный намеренно: pacman на установленной системе
скачивает обновления без входа в GitHub, поэтому закрытым он быть
не может. Секретов здесь нет — только пакеты и база репозитория.

## Подпись пакетов (GPG)

Пакеты XrOS подписываются ключом проекта (Ed25519, только подпись):

- Отпечаток: `0EC935D2A8E31AEC1878BBE5797805A298A55BAA`
- Владелец: `XrOS Project (XrOS Security Updates) <xros@xros.example>`
- Публичный ключ: [xros-public.key](xros-public.key) в этом репозитории.

Честное состояние на 11.11.2026: ключ сгенерирован и опубликован здесь,
но пакеты в репозитории пока НЕ подписаны, а в системе по-прежнему
`SigLevel = Optional TrustAll` — проверка подписи ещё не включена.
Автообновления остаются выключенными, пока подписание не будет проверено
на тестовом репозитории (отказ неподписанному пакету и плохой подписи).
Приватный ключ никогда не публикуется и не попадает в ISO или git.
